# 假负载测试流程 — 当前版本禁止真实耳机

**当前设计没有通过仿真验收，本文是下一版修订后的测试清单，不是批准给这版接市电。** 先解决 DESIGN_REPORT.md 中的保护、纹波和模型问题，再由具备高压经验的人员审查接线、绝缘、PE、器件 SOA 与仪器接地方式。

## 测试设备和记录

隔离的可调交流测试源、适合高压节点的差分探头、万用表、双通道示波器、音频分析仪/经校准的采集链、温度探头；16Ω 和 18Ω 非感性假负载，功率与脉冲能力须根据故障能量选定。故障试验使用带限流的独立故障源和有能量额定值的隔离工装。

记录管号、两半管实测曲线、所有关键电阻/电容实测值、环境温度、市电、仪器型号/校准状态、探头接法、音量位置、输入源阻抗和原始波形。不要把软件截图或仿真 DRC 作为物理证据。

## 0. 不通电检查

1. 核对管座**底视图**：4/5 灯丝，9 屏蔽，1/2/3 与 6/7/8 两半管；核对 MOSFET、LDO 的金属片电位和绝缘片。
2. 对照 BoardSpec 逐网通断核对；输入/输出插座与机箱绝缘，只有 LK1 是预定信号地/机箱单点连接；PE 独立螺栓，不经开关或保险。
3. 由合格人员确认变压器加强绝缘、绕组端子、熔断器类型、爬电/电气间隙、护罩、防误触和接地连续性。功能端名不是任一具体接插件/继电器的焊盘号。
4. 测每只输出电容的容量、ESR、漏电；按实际偏置、温度和稳定时间测量。2mV/16Ω 只允许约125uA**总**直流，其中还包括保护监测电路注入，不能把125uA全留给电容。
5. 验证泄放路径含 HV_RAW、HV_IN、BPLUS 和每声道 MID。断电后等待并逐点测量；**不能仅按经过时间判定安全**。COUT 储能约3.4J，MID=100k 与 OUT=10k 的理想放电时间常数约110s，容差和故障会延长。

## 1. 低压供电与控制单独验证

先断开高压绕组和胆管音频供电，用限流低压源验证 AUX12、分立延时、掉电复位和正/负 DC 检测。继电器接假负载，示波器同时记录输入事件、检测节点、线圈和触点后的输出。

- 测实际吸合、释放、反跳，不能以线圈电压代替触点状态。
- 用有界小电压注入验证检测极性、阈值和两声道“任一故障关闭两路”的行为。
- 若复位延迟、检测网络输出偏置、继电器释放不满足经审查的安全包络，立即停止，不进入高压。

## 2. 电源带假负载

先用电阻代替胆管：B+模拟两声道总负载，灯丝逐步到1.8A和2.5A。验证198/220/242VAC、最低储能容量、启动和快速重启。测绕组RMS电流、桥堆/储能电容纹波电流、MOSFET和LDO壳温及散热器温度；由实际热阻推算结温并留裕量。

- 测 B+均值和完整频谱，检查稳压环路振铃/振荡、启动过冲、负载阶跃。
- 测 HPLUS-HMINUS=6.0–6.6V，灯丝抬升约38V，所有热态/冷态下的 Vhk。
- 实测高压泄放时间；验证断电后储能节点的电压下降。
- MOSFET连续线性SOA、变压器浪涌、保险分断和绝缘尚未批准时，不可推进。

## 3. 胆管 + 假负载音频

1. 插入管子，保持真实耳机完全断开。记录上下半管各电压与电流；额定输入每半管Pa<=3.2W；所有检查角点不超过保守额定值，Ia连续<=50mA。
2. 测16Ω、18Ω，高低档与相同音量位置。输出100mVrms所需输入<=1Vrms；档差20±0.5dB；20Hz–20kHz相对1kHz偏差±0.5dB。
3. 1kHz输出50mVrms THD<=0.1%，100mVrms THD<=0.5%；量测链本底需显著低于目标。
4. 输入短路、固定音量，分别测20Hz–20kHz噪声、100Hz及谐波、灯丝/磁场耦合；不以SPICE无噪声胆管模型替代。
5. 测有载与空载DC、实际电容漏电贡献、输出阻抗随频率变化。稳态耳机端DC<=2mV。测得耳机复阻抗前，不宣称实际耳机频响已通过。

## 4. 瞬态和故障

在专用工装中分别验证开机、关机、快速重启、单支管慢热/失效、两档切换、开关反跳、输入源DC偏置、插拔、空载、16/18Ω、短路、输出电容漏电/开路/短路。

- 故障开始时刻、触点实际断开时刻、峰值、脉宽和负载能量均须保存原始波形。
- 从小能量故障源逐步推进；不能用真实耳机试探保护是否工作。
- 当前候选的硬短路代理已严重失败；在保护重新设计并独立审查前，不进行高能量短路试验。
- 没有耳机厂家的可接受瞬态电压/能量数据，不能自定一个能量阈值后宣称“保护通过”。
