# STC51 电子时钟真实 EDA E2E 证据（2026-09-14）

## 结论

- 新增一份可校验的 5 V STC89C52RC + DS1302 电子时钟 BoardSpec 和 17 类真实 EasyEDA 器件定义。
- 在 EasyEDA Pro 活动画布上完成 25 个器件、21 个网络、76 个连接节点的导入、确定性摆放、板框、双层自动布线、局部重布和 Bottom GND 覆铜重建。
- 最终 PCB 包含 224 条铜线、7 个过孔、1 个板框 Polyline、1 个 Pour 和 1 个 Poured 实例；器件 BBox 无重叠、无板外器件，严格 PCB DRC 为 0。
- BoardSpec 与链接 PCB 的 Protel2 回读、以及最终自由 PCB 的焊盘网络图，均为 25/25 components、21/21 nets、76/76 nodes，missing、extra、changed 全部为空。
- 这是一份连接与 Layout 工具链的实机夹具，不包含固件编译、烧录、晶振起振测量、走时精度测试或实物 EMC/可靠性验证，不应视为量产设计。

## 电路边界

电路使用 STC89C52RC PDIP-40、11.0592 MHz 主晶振、DS1302 与 32.768 kHz/6 pF 晶振、CR2032 后备电池、三个设置按键和一个复位按键、UART ISP 接口，以及由 SS8050 驱动并带反向二极管的 5 V 蜂鸣器。STC 官方资料确认该系列为 8051 内核、工作电压 3.3–5.5 V，并支持内部或外部时钟；DS1302 官方资料确认 CE/I/O/SCLK 三线接口、双电源和 32.768 kHz 晶振连接方式：

- <https://www.stcmicro.com/STC/STC89C52RC.html>
- <https://www.analog.com/media/en/technical-documentation/data-sheets/ds1302.pdf>

EasyEDA 系统库中名为 LCD1602 I2C 的搜索结果实际是 16-pin 并行屏器件，不能假定含 I2C 转接板。本夹具因此把显示器边界建模为 4-pin 外接模块 H1，并明确限定 `1=VCC, 2=GND, 3=SDA, 4=SCL`；实物模块的针序和 I2C 地址仍须人工核对。H2 的 STC ISP 适配器针序也同样作为外部接口约束处理。

BoardSpec 校验返回 `ok=true`、0 errors、0 warnings，并成功生成 Protel2 网表、BOM CSV 和 Mermaid 连接图。未使用的 MCU 引脚和蜂鸣器机械焊盘均显式标为 No Connect。

## 本次实机修复

EasyEDA 的完整 DRC 违规对象可能含字符串数组元数据。原归一化器在已经识别并输出该违规后仍继续递归，导致 `SMD Pad` 或 `Connection Error` 被误记为额外一条 `EDA DRC`。现在完整违规对象只输出一次、不再遍历内部说明字段，并增加回归测试；真正的顶层字符串诊断仍会保留。
